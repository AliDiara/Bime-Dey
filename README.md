# پیگیری تمدید بیمه (بیمه دی)

PWA فارسی برای نماینده و کارمندان: ایمپورت خروجی اکسل بیمه دی، ثبت اقدام تماس، داشبورد سررسیدها.
دیتابیس = Google Sheet خود نماینده، با Google Apps Script به‌عنوان بک‌اند.

## ساختار
- `backend/Code.gs` — کد Apps Script (API، کاربران، قفل همزمانی)
- `app/` — برنامه (HTML/JS خالص، بدون build). `index.html`, `app.js`, `jalali.js`, `sw.js`, `manifest.json`
- `sample/` — نمونه اکسل بیمه دی

## راه‌اندازی (یک‌بار، توسط نماینده)
1. یک Google Sheet خالی بسازید.
2. منوی Extensions > Apps Script را باز کنید، محتوای `backend/Code.gs` را جایگزین کنید و ذخیره کنید.
3. Deploy > New deployment > نوع Web app. Execute as: **Me**. Who has access: **Anyone**. مجوزها را تأیید کنید.
4. آدرس Web App (که به `/exec` ختم می‌شود) را کپی کنید.
5. پوشه `app/` را روی یک هاست HTTPS استاتیک بگذارید (Cloudflare Pages، Netlify، GitHub Pages).
6. برنامه را باز کنید، آدرس را وارد کنید، حساب مدیر را بسازید.
7. تب «مدیریت»: اکسل را ایمپورت کنید، کارمندان را اضافه کنید، «لینک کارمندان» را برایشان بفرستید.
8. روی گوشی: Add to Home Screen.

## نکات
- بعد از هر تغییر در `Code.gs` باید Deploy > Manage deployments > Edit > New version بزنید.
- ایمپورت دوباره: با شماره بیمه‌نامه ادغام می‌شود و اقدامات قبلی پاک نمی‌شود.
- کارمند فقط روی پرونده‌های بدون مسئول یا واگذارشده به خودش اقدام می‌کند. مدیر روی همه.
- حالت آزمایشی (دمو) در صفحه ورود: داده در مرورگر ذخیره می‌شود، بدون گوگل.
- رمزها با SHA-256 و salt در شیت Users ذخیره می‌شوند. شیت را با کسی به‌اشتراک نگذارید.
